Hello, reader! And welcome to the official website of Vindur Games. We are excited to have you join
us! Read on if you want to learn more about us...

<!-- excerpt -->

> Vindur Games is an unofficial, small group of independent game developers that love to make video
> games as a pastime.

Not very fancy, I know, but it's the fanciest description I could come up with. Through our endless
experiments and tangents, we end up creating many small things: [video game prototypes](/games),
[tidbits of music](https://open.spotify.com/artist/0i6oObeqD3Tueuq0nLWQ50?si=IR8yCvqHTJmLsojk_z2ydg),
[helpful game dev tools](/docs), [blog posts](/blog), the list goes on. This site is intended to be
a place where we can share these wonderful things with the rest of the world. The fact that you're
reading this is proof we've managed to do just that, so thank you 😊
